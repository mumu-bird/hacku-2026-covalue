# 三分钟演示与讲解

全部人物、能力记录、价格系数、历史及资金均为模拟。录制为WebM，1280×800，有解释字幕，无语音。核心操作直接运行本地应用，没有剪辑伪造业务结果。

| 时间 | 操作与讲解 |
|---|---|
| 0:00–0:15 | 先尝试60↔60：同一小时可以有不同能力、投入和用途。 |
| 0:15–0:34 | 两人实际保存并授权分享收到服务的个人价值80／200，与平台100／150参考并列；全部是合成演示判断。 |
| 0:34–0:49 | 重新计算得到60↔90。数量改变后旧判断失效；不是永久汇率。 |
| 0:49–1:04 | 一方至少90，另一方最多60：实际计算无交集，不成单、不扣信用。 |
| 1:04–1:21 | 更新接受条件，选用合法90候选，双方确认两轮30↔45合同。 |
| 1:21–1:38 | 实际提交并验收首项30分钟辅导；原45分钟英语仍未完成。 |
| 1:38–1:54 | 先履约者退出，双方双签继续原45分钟回报、豁免未开始下一轮，订单保持结清中。 |
| 1:54–2:09 | 实际补完45分钟，订单取消结清；个人页保留提供30／收到45，不作分钟净额抵扣。 |
| 2:09–2:25 | 展示30／60分钟先行限制的投入与操作计数取舍：4轮18命令／2轮10命令。 |
| 2:25–2:39 | 实际运行无能力证据案例，暂停确定建议并说明先复核。 |
| 2:39–2:54 | 实际运行31分钟准备无法合法分轮，说明规则失效；18组控制实验不当作市场价格验证。 |
| 2:54–3:00 | 真实试用任务及匿名反馈；独立反馈尚未收集，不将演示身份当研究人数。 |

现场运行`./scripts/start.sh`，进入“演示模式”切换五个独立案例、当事人和复核员。新版自动录制必须使用独立服务：

```bash
HOURLINK_DATA_DIR=tmp/recording/data uv run uvicorn backend.app.main:app --host 127.0.0.1 --port 8003
# 另一个终端
node scripts/record-demo.cjs
```

脚本实际操作网页并核对响应与终态，输出原视频`artifacts/browser/recording/hourlink-raw.webm`、metadata中的storyOffsetSeconds、trace和截图。用ffmpeg按该起点裁取约180秒至`artifacts/hourlink-demo.webm`，不改变业务速度或结果。录制不使用正在浏览的8000端口数据库。

新版完整展示时间互换、主观分歧、不成交、先履约者退出及补完原回报。付费和补差另有完整浏览器验收；补差固定60↔60、模拟50港币，每轮双方服务验收后释放。匿名试用页只下载到参与者设备，不上传或自动统计反馈。
