# 三分钟演示与讲解

全部人物、能力记录、价格系数、历史及资金均为模拟。录制为WebM，1280×800，有解释字幕，无语音。核心操作直接运行本地应用，没有剪辑伪造业务结果。

| 时间 | 操作与讲解 |
|---|---|
| 0:00–0:15 | 从社区真实形态的表格需求开始：平台帮助量化付出、找到合适的人。 |
| 0:15–0:32 | 展示三人能力依据、预计工时、总价：时薪300×半小时=150，250×1小时=250，200×1.5小时=300。不能只看时薪。 |
| 0:32–0:48 | 展开林知行的相关证据，解释技能覆盖、质量、独立对手数和历史中位数。 |
| 0:48–1:04 | 生成平台默认方案，建议是演示参数，可继续协商；建两阶段合同。 |
| 1:04–1:20 | 周予安及林知行分别确认同版协议，平台检查需求锁、容量和时间。 |
| 1:20–1:39 | 预留第一阶段，切换提供者提交成果和实际时间。 |
| 1:39–1:55 | 接收者验收；确认贡献、释放金额和解锁下一阶段一起完成。 |
| 1:55–2:13 | 切换互换案例，展示60分钟表格辅导↔90分钟英语，分两轮30↔45。不是永久汇率。 |
| 2:13–2:30 | 切换部分履约退出：HK$60已释放，HK$90预留；逐项取消原剩余阶段并退款。 |
| 2:30–2:47 | 双方确认结清，保留既有贡献。解释时间互换中原回报义务仍保留。 |
| 2:47–3:00 | 分类能力与时间账本；解释更多验收成本、线下真实性限制，演示不承诺真实支付担保。 |

复现场景：先运行 `./scripts/start.sh`。进入“演示模式”，切换付费成功、没有可行方案、部分履约后退出、时间互换、互换补差；右上角切换当事人和复核员。复核员可重置当前案例。录制脚本默认用Codex本机Playwright，运行 `node scripts/record-demo.cjs`。

录制同时完整展示付费、互换建议和退出退款；互换真实履约及先提供者退出后仍获原45分钟服务，由自动化交易／结清测试验证，可现场演示。补差案例固定60↔60，周予安向林知行补HK$50，本轮双方验收完再释放。
