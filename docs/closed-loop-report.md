## 本轮修复

- 争议复核恢复状态时保留已提出的退出；其他争议未解决时保持暂停，防止提前释放资金或开放下一轮。
- 暂停期间已确认的交付事实保留，恢复后继续推进已验收阶段；结清履约控件须等待双方确认继续原义务。
- 辅助协商无交集不能绕过计算直接建单；签署时重新检查当前共同接受范围。合法候选使用原子选择接口，保留同服务私人条件及可执行轮数。
- 互换在有界合法分钟集合中选择最接近接受区间中点的可执行候选，包含时间窗口边界和分轮限制；补差重算使用当前反向时长。
- 模板未加载时禁用分类及提交，避免空技能和空验收标准进入表单。

## 数据库独立检查

对每个快照执行SQLite完整性和外键检查，逐条资金流水重建每人可用／预留余额，核对支付意图的预留、释放、退回字段与业务键唯一性。11个演示账户的总资金始终为1,100,000港仙（HK$11,000）。

完成和取消订单均没有未结义务、开放争议、残留预留款或时段预订。取消的部分履约不伪装为完整能力历史；完成订单按真实服务提供者生成历史，历史确认执行分钟与已验收时间明细一致。确认时间只归属ACCEPTED义务。

55项后端测试还覆盖越权读取和操作、版本冲突、重复命令、真正并发第二签争夺容量、重复对手／作品证据上限、建议失效、付款方向、超时不自动验收、违约限制与完成补救后解除，以及价值判断授权／失效和控制实验边界。
