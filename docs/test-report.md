## 已覆盖的业务风险

- 不同需求对同一个人的评分和排序可以不同；必需技能、难度和时间冲突先过滤。
- 初级证据不能证明高级能力；无证据不生成质量分或溢价。重复对手、作品及测评受上限约束，跨类成绩不迁移。
- 三个独立相同难度及工作量的历史样本才生成历史耗时中位数；仅两个样本用公开模板。
- 更高时薪可能更低总价；纳入准备时间改变价值和交换数量，推荐同时计算可执行轮数。
- 反向时段／方式不符不生成可行方案；费用和时间单列，纯互换不暗藏现金费用。
- 私人条件仅本人读取；无可行辅助方案不成单、不扣信用。价格可自由协商。
- 未签推荐随证据／需求变化失效；已签协议不被后来能力、需求变化改写。
- 付款方权限、不可自验收、同版本双签；第二签原子检查容量、需求锁及预订。
- 并发抢同一需求只有一单激活；重复命令、重复预留及重复验收不会重复记账；版本和幂等键内容冲突拒绝。
- 正常付费、零金额付费、互换、两种补差付款方向；阶段服务和资金同步推进、整体资金守恒。
- 部分付费退出保留HK$60已释放，HK$90退原付款方；互换退出保留原45分钟回报，补差退出继续服务时资金保持预留。
- 争议、重做、期限超时、补救、在途容量；未确认成果不计贡献，未完成订单不计能力历史。
- 五个案例隔离、复核员重置、关闭演示模式禁用入口；刷新保留状态。

浏览器实际点击需求、展开评估、选择候选、建立协议、切换双方、双签、预留、提交、验收、刷新和个人时间页。拦截非本机请求时核心流程仍成功，无外部服务请求，桌面无页面异常；手机无横向溢出。

本次新增辅助协商共同接受范围的建单／签署检查、原子候选选择、互换时段边界与轮数校验、修改反向时长后的补差重算、争议与退出交叠处理，以及模板延迟加载验证。详细步骤与结果见 [闭环验收记录](closed-loop-report.md)。
